최종 갱신일: 2026-05-14

1. 수집 항목

  • 익명 ID (UUID) — 디바이스 첫 실행 시 자동 부여. 본인 식별 불가.
  • 학습 진도 — 단어/책/별표/완독/스트릭 등. 모든 데이터는 본인 학습용.
  • 설정값 — 언어, 다크모드, 폰트, 알림 시간 등.

이름·이메일·연락처·주소·결제정보·위치정보는 수집하지 않습니다.

2. 외부 서비스 연동

  • Google Translate — 단어/문장 번역 API 호출 (단어 텍스트만 전송).
  • archive.org · LibriVox — 오디오북 스트리밍 (별도 가입 불필요).
  • jsDelivr · GitHub Pages — 원문 도서·칼럼 콘텐츠 OTA 배포.
  • Supabase — 익명 ID 기준 학습 진도 클라우드 백업 (선택적).
  • Sentry — 앱 크래시·오류 진단 (개인 식별 비활성).

3. 회원 가입

회원 가입은 필요하지 않습니다. 모든 기능은 현재 무료로 제공됩니다.

4. 데이터 저장 위치

  • 로컬: 디바이스 내 IndexedDB / localStorage (오프라인 사용 가능).
  • 클라우드 (선택): Supabase — 데이터는 EU/US 데이터 센터에 저장될 수 있음.

5. 사용자 권리

  • 앱 내 Settings 에서 학습 진도 내보내기 / 가져오기 / 초기화 가능.
  • 익명 ID 기반이므로 디바이스 초기화 또는 앱 삭제 시 모든 학습 데이터 함께 삭제됨.
  • 클라우드 데이터 삭제 요청은 young@tellet.com 로 익명 ID 와 함께 요청.

6. 결제 및 환불

현재 본 앱의 모든 기능은 무료로 제공됩니다. 향후 유료 기능이 추가되는 경우 본 약관이 사전에 갱신될 예정입니다.

7. 콘텐츠 출처 및 저작권

  • 영어 원문: Project Gutenberg (퍼블릭 도메인).
  • 오디오: LibriVox 자원봉사자 녹음 (퍼블릭 도메인).
  • 한국어 및 다국어 번역: AI 보조 (Anthropic Claude) 생성 후 운영팀 편집.
  • AI 보조 콘텐츠 특성상 오역·부정확 가능. 발견 시 young@tellet.com.
